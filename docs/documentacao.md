# Documentação do Projeto Farmatech

## Visão Geral
Sistema web para gerenciamento de farmácia, incluindo cadastro de clientes e remédios.

## Estrutura Técnica
- Backend: Node.js + Express
- Frontend: HTML/CSS/JS vanilla
- Comunicação: REST API
