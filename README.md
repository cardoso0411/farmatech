# Sistema Web para Farmácia

Este projeto é um sistema web para gerenciar cadastros de clientes e remédios em uma farmácia local.

## Estrutura do Projeto

- `backend/`: Contém o código do servidor backend (Node.js com Express)
- `frontend/`: Contém o código do frontend (HTML, CSS, JavaScript)
- `public/`: Arquivos estáticos (imagens, CSS, JS)
- `docs/`: Documentação do projeto

## Funcionalidades

- Cadastro de clientes
- Cadastro de remédios
- Interface web simples para gerenciamento

## Como executar

1. Instalar dependências: `npm install` no diretório backend
2. Executar o servidor: `node server.js` no backend
3. Abrir `index.html` no frontend no navegador

## Tecnologias

- Backend: Node.js, Express
- Frontend: HTML, CSS, JavaScript
- Banco de dados: (a definir, talvez mysql ou MongoDB)
